## 🎯 How It Works

```
User Opens Learning Category
    ↓
System loads 50 questions from question_data.dart
    ↓
Displays VisualQuestionPage showing:
  • Large image (280×280) or emoji
  • English word
  • Tamil translation
  • Difficulty badge (Easy/Medium/Hard)
  • Progress bar (e.g., 5/50)
    ↓
User navigates:
  • Click "Next" to see question 6
  • Click "Previous" to go back
  • Progress updates automatically
    ↓
Repeats for all 50 questions
    ↓
User completes category
```

## 🖼️ Adding Images (Optional)

When you're ready to add real images:

1. **Get 50 PNG images** (256×256 pixels each)
   - Download from Unsplash, Pexels, or Pixabay
   - Or create your own using Figma/Canva
   - Or use AI image generators

2. **Name them correctly**:
   - 1_water.png, 2_food.png, ... 50_scared.png

3. **Place in**: `assets/images/questions/`

4. **Run app** - Images auto-load!

**No code changes needed!** The app automatically uses PNG images when available, falls back to emoji otherwise.
